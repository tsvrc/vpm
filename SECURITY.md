# Security policy

## Reporting a vulnerability

Don't open a public issue. Use
[GitHub private vulnerability reporting](https://github.com/tsvrc/vpm/security/advisories/new)
for this repository instead, so the report isn't visible before a fix is available.

If that's not accessible to you for some reason, contact
[@ToniSeas](https://github.com/ToniSeas) directly.

## Scope

This covers the listing build in this repository: `source.json`, `Website/` and the workflows. A
vulnerability in a listed package belongs to the repository of that package, as its `SECURITY.md`
describes.

## Supported versions

Only the current `main` is supported. The listing itself has no versions.

## Response

This project is maintained by one person in their spare time. There's no guaranteed response time,
but security reports get priority over other issues.
